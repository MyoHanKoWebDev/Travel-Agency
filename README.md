# Travel Agency
## Overview
Travel Agency is a web platform designed to help users explore, book, and manage travel packages. Built using PHP, Bootstrap, HTML, CSS, and JavaScript, this project provides a seamless experience for travelers looking to plan trips efficiently.

## Features
✈ User registration & login

📄 Browse and view travel packages

🛒 Book trips and manage reservations

🔍 Search and filter packages by location or category

⭐ Rate and review travel experiences

🕹 Responsive design for all screen sizes

📊 Admin panel for managing packages and bookings

## Tech
[PHP] - Backend Logic

[MySQL] - Database

[HTML/CSS] - Structure & Styling

[Bootstrap] - Layout & Design

[JavaScript] - Interactivity

[Git/GitHub] - Version Control

## Setup Instructions
Clone this repo or download ZIP

Import the SQL file to your local database (phpMyAdmin)

Run the app using XAMPP

Access it via http://localhost/Travel-Agency/user/travel-agency-html-template/index.php

🗂️ Importing the Database
A SQL file is included in the project folder (/travel-agency/travel-agency-db.sql) to help you set up the database quickly.

📥 Steps to Import:
Open phpMyAdmin via your local server (e.g., XAMPP).

Create a new database named `travel_agency`.

Click on the newly created database, then go to the Import tab.

Choose the file: travel-agency/travel-agency-db.sql

Click Go to import the tables and data.

✅ You should now see all tables successfully created in your travel_agency database.
